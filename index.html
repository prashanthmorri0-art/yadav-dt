Artificial Intelligence

AI is a technology that enables computers to perform tasks that usually require human intelligence.

Example: Virtual assistants and chatbots.

Intelligence

Machine Learning

ML is a part of AI that enables computers to learn patterns from data and make predictions.

Example: Movie recommendations.

Learning from data
🧠

Deep Learning

Deep Learning uses neural networks with multiple layers to learn complex patterns.

Example: Image and speech recognition.
